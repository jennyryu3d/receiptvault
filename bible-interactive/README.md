# Bible Interactive

성경 스토리를 원작으로 한 인터랙티브 무비. 미래에서 온 인물이 과거의 사건을
목격하는 프레임 서사 위에, 프리렌더 시네마틱과 웹 인터랙션 레이어를 얹는다.

> **상태: 기획 단계.** 아직 코드도 에셋도 없다. 지금 있는 것은 결정과 그 이유뿐이다.
